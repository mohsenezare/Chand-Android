# Chand 2.2 — نسخه نهایی Live Clean

- ادغام بازارهای TGJU و نمادهای فعال بورس در یک فهرست «بازارها».
- حذف نمادهای آرشیوی، منقضی و رکوردهای قدیمی TGJU با اعتبارسنجی قیمت و تاریخ به‌روزرسانی.
- پاک‌سازی خودکار نمادهای بورسی قدیمی از انتخاب‌های ذخیره‌شده، فقط پس از دریافت یک فهرست کامل و معتبر بازار.
- بروزرسانی نمادهای TGJU از WebSocket زنده و بروزرسانی نمادهای بورس با چرخه حدود ۰.۹ ثانیه هنگام باز بودن برنامه.
- کاهش کش TSETMC از ۱۰ ثانیه به ۶۵۰ میلی‌ثانیه.
- افزودن fallback رسمی `webgw.tse.ir` برای Cash و ETF در صورت خالی/مسدود بودن MarketWatch قدیمی TSETMC.
- استفاده از User-Agent مرورگر برای سازگاری بهتر با TSETMC.
- حذف کامل پیام‌های هشدار منبع از صفحه اصلی.
- لوگو/Badge اختصاصی‌تر برای طلا، سکه، نقره، نفت، ارز، رمزارز، شاخص، خودرو و نمادهای بورسی؛ همه آیتم‌های صفحه اصلی Badge دارند.
