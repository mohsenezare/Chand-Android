# اصلاحات نسخه 2.3

- حذف کامل نمایش هشدار منبع از صفحه اصلی.
- Badge/لوگوی مرتبط برای ارز، طلا/سکه، نقره، رمزارز، نفت/انرژی، شاخص، خودرو و نمادهای بورس؛ برای نمادهای بورسی از نام همان نماد روی Badge استفاده می‌شود تا همه یک آیکن یکسان TSE نداشته باشند.
- WebSocket برای داده‌های زنده TGJU و polling سریع برای نمادهای بورس.
- کش TSETMC کوتاه و fallback رسمی به webgw.tse.ir.
- اگر بازار بسته/نماد متوقف باشد و last/close امروز صفر باشد، قیمت دیروز/آخرین مرجع رسمی نمایش داده می‌شود تا کارت بی‌قیمت نماند.
- نمادهای منقضی/آرشیوی TGJU فیلتر می‌شوند و universe بورس فقط بعد از دریافت فهرست معتبر پاک‌سازی می‌شود.
- نسخه: 2.3-final (versionCode 8).
